第二步：掃描條碼（密碼 → 門號） 0 / 0

第三步：教 OCR 位置（PO Number & Requester） 未鎖定位置
1. 先揀「教 PO Number (3401...)」，喺 GRN 上拖曳框出 PO 號碼位置。
2. 再揀「教 Requester」，喺 GRN 上拖曳框出 Requestor 位置。
3. 框好後按「鎖定位置並套用全部」——設定後就唔會再亂改！
第四步：逐張核對 GRN（高清放大 + 紅框標示） 0 / 0
用鎖定咗嘅位置跑 OCR；按「高清放大 / 還原」可以睇清楚字跡、摺痕同紅框位置有冇讀錯。
